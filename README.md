# Document Ready

A checklist and online application helper for common government services in Cameroon.

## Features

- User register and login with password (localStorage)
- Side navigation bar with hover open on mobile
- Light and dark mode
- 12 services with search and category filter
- Document checklist with sample completed documents
- Application form and progress tracking on dashboard
- Responsive on phone, tablet and desktop
- Header, footer and services loaded from JavaScript
- Three CSS files: main, layout, components

## How to run

Open `index.html` in a browser, or serve the folder with any static server.

## Pages

- `index.html` – Landing (must register / login to enter)
- `pages/register.html` – Create account then go to login
- `pages/login.html` – Sign in
- `pages/dashboard.html` – Progress overview
- `pages/services.html` – List, search, filter, Apply buttons
- `pages/apply.html` – Checklist, samples, form for one service
- `pages/about.html` – About the project
- `pages/faq.html` – Frequently asked questions

## Note

Not an official government site. No payment or receipt. Data stays in the browser.
